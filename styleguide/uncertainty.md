# Uncertainty

Uncertainty is native to subsurface work, so it is a first-class feature, not a footnote.

## P90 / P50 / P10

- **Oilfield convention:** P90 means a 90% probability that the true value **exceeds** the amount,
  so P90 is the **low** case and P10 the high case. This is the reverse of a statistical 90th
  percentile. Label it the oilfield way ("P90 (low)") and explain it once in the appendix.
- Resource classes follow PRMS where relevant (1P/2P/3P, 1C/2C/3C); name the system used.
- In prose: "around X (P90–P10: A–B)". The P50 is never quoted without its range.

## Forms, from Core to Outcrop

| Form | Register | Use |
|---|---|---|
| Range bar: P90–P10 whisker with a P50 tick | Core | Compare many prospects or fields |
| Range table: P90 / P50 / P10 columns with an inline range bar | Core | Exact values plus shape |
| Fan chart | Section | Profiles over time (production, pressure) |
| Exceedance curve | Section | The industry-standard probability plot for one estimate |
| Density gradient bar (darkest at P50, fading to the tails) | Outcrop | A memorable single estimate |
| Value-by-confidence maps (fade where evidence is sparse) | Section | Spatial uncertainty |

## Chance of success

- Geological chance of success is the product of the play elements (source, reservoir, trap, seal,
  charge and timing); show it as a product, so the reader sees which element dominates the risk.
- Pre-drill predictions and post-drill results are shown together whenever both exist.

## Rules

- Interpreted values never appear without a range or a stated assumption.
- Ranges use the same colour as their P50, lighter; never a new hue.
- Simulated outcomes are labelled as simulations.
