# Registers

A register sets how much ornament and how custom a form may be. It can be set for the story and
overridden per figure (`register:` in a block). The truth gate applies in all three.

| | **Core** | **Section** (default) | **Outcrop** |
|---|---|---|---|
| Like | A core sample: dense, precise | A geological cross-section: interpreted, explanatory | An outcrop: exposed, dramatic |
| Tradition | Few, Tufte; the executive brief | Cairo; data journalism | Bremer, Wu; data art |
| Purpose | Decide, approve, sell the case | Explain, persuade, engage | Hook, wonder, remember |
| Forms | Standard forms, tables, small multiples | Standard forms plus one unique touch | Custom metaphors and glyphs |
| Effects | None | Subtle, where they encode data (e.g. a gradient for uncertainty) | Glow, gradients, particles, dark backgrounds (uniform behind data) |
| Motion | State changes only | Staged d3 transitions | Choreographed: explode and regroup, force layouts |
| Obligations | Action titles; exact values available | Annotation and fact strip | A "how to read this" step, and a **standard view** toggle showing the same data as a conventional chart |

## Guidance **[Default]**

- **One Outcrop moment per story** is usually enough: typically the opening hook (Bremer: draw people
  in before insight can land). Wu's caution applies: flashy is not the goal; the story has to resonate.
- **Creativity is the extra layer on top** (Bremer), never bigger than the story.
- **Positions may be nudged for aesthetics** only while marks stay "near where they should be" (Wu),
  and never in Core.
- **Let the subject guide the form:** strata, cores, wiggle traces, contours, well paths, starfields
  of discoveries.
- **Teach the encoding:** an unusual form explains one mark in detail before asking the reader to read
  many.
